# Technical Training Exercises

This repo contains an Odoo module from the technical training exercises. 

The Technical Training course with videos and written Server Framework 101 Tutorial are nearly identical with the changes noted below. 

Minor Differences:
1. The written tutorial skips Video 3 (Data introduction)
2. Chapter 8 (written)/Video 9: the written directions have more specificity as to what to set the garden-related values to on the toggling of the ```garden``` field
3. Chatper 4/Video 4: The video has you give rwcd permissions to admin and read permissions to base.group_user, and the written tutorial has you give rwcd to the base user. I followed the video on this.
